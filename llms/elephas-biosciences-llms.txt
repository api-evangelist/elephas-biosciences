# Elephas Biosciences

> Elephas Biosciences Corporation (Madison, Wisconsin) builds elive, a functional
> immune-profiling platform that measures how a patient's own live tumor tissue
> responds to immunotherapy. Elephas publishes no public API, no developer portal
> and no machine-readable contract. Its only digital surface is the Elephas Portal,
> a customer-authenticated web application through which clinicians and research
> partners receive elive test reports. This file was generated by API Evangelist
> from probed evidence; it is not published by Elephas.

## APIs

- Elephas Portal API — https://portal.elephasapis.com — PRIVATE. An ASP.NET Core
  (Kestrel) service that answers every path, including /swagger and
  /swagger/v1/swagger.json, with HTTP 401 and a WWW-Authenticate: Bearer challenge.
  Human entry point: https://portal.elephas.com/
- There is no public API, no sandbox, no API key issuance and no developer sign-up.
